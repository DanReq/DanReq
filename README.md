## Featured Projects

### Quiton – Salesforce AI Sales Reporting Automation

Salesforce + FastAPI project focused on automating sales reports through Salesforce Flows, Apex Invocable Actions, REST API integration, Python-based data processing, and Agentforce-oriented prompt design.

**Tech Stack:** Salesforce · Agentforce · Apex · Flows · FastAPI · Python · Pandas · REST APIs

**Main Contributions:**

* Integrated Salesforce with an external REST API to automate sales reporting.
* Implemented Salesforce Flows to capture report requests, process parameters, and store results in custom objects.
* Configured external service connections using Named Credentials, External Credentials, and Apex Invocable Actions.
* Developed Python logic for data cleaning, business metric calculation, and sales report generation.
* Designed prompts to support efficient report generation and interaction with Agentforce.

**Status:** Public release pending hackathon completion.
A sanitized public version will be published after the hackathon concludes.
